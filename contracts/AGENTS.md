# contracts/AGENTS.md — зона контракта-шва

**Ты под ZTACP.** Канон: `../docs/ztacp-pattern.md` (1.0-rc9). Корневая конституция: `../AGENTS.md`.

## Что это

`contracts/` — шов между backend и frontend: `openapi.yaml` и производные схемы. Единственная точка межзонного доверия (B1/I4). Писать сюда может **только координатор** (single-writer, B3/I5); воркеры зоны не имеют.

## Правила шва

- Воркер backend/frontend: изменение контракта — предложение координатору (PR/описание с обоснованием), не правка.
- Контракт версионируется (semver): ломающее изменение поверхности = major; добавление = minor.
- Потребители работают от моков из схем (B2): пока сосед не готов — мок по схеме, не пауза.
- Память шва: git-история; force-push на `contracts/` запрещён.

## Для координатора

- Это твои общие файлы: коммиты с префиксом `shared:`.
- Изменение семантики шва, ломающее потребителей, — только с уведомлением обеих зон и фиксацией в `../PLAN.md` (D1).
- Ты под законом как все: властные акты — с evidence (E11/I29); мандат «строить, не ломать» (A11/I41).
