# research/ — корпус кейс-стади ZTACP (6.12, I39)

Один проект — один кейс-файл `case-<дата>-<проект>.md` по `TEMPLATE.md`. Регистрация — при Genesis; кейсовая запись — при закрытии (любой род ликвидации). События не дублируются руками: они уже пишутся в `.ztacp/*.log` (sanctions, incidents, lease takeover, projects). Кейсы — append-only память (I21): дополняются, не переписываются. Корпус принадлежит принципалу (диплом/статья).
